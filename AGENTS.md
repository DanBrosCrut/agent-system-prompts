# Agent Instructions

## Проект
Backend API для интеграции с МойСклад.

## Стек
Java 21, Spring Boot 4.x, Maven

## Workflow
1. Всегда создавать ветку под задачу
2. Не пушить в main напрямую
3. Писать коммиты по Conventional Commits

## Запрещено
- Коммитить секреты (токены, пароли)
- Пушить в main
- Использовать deprecated API
